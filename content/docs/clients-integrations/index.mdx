## Phạm vi dự kiến

Nhóm này hướng dẫn từ REST API đến các client chính thức và việc đưa telemetry vào Elastic qua OpenTelemetry.

## Các bài trong nhóm

- [REST API](./rest-api) — Sử dụng REST API để quản lý cluster, index, document và search.
- [JavaScript client](./javascript-client) — Kết nối Node.js hoặc ứng dụng JavaScript với Elasticsearch bằng client chính thức.
- [Python client](./python-client) — Xây dựng integration Python cho indexing, search và quản trị Elasticsearch.
- [Java client](./java-client) — Sử dụng Java API Client trong ứng dụng JVM và quản lý request type-safe.
- [Go client](./go-client) — Kết nối ứng dụng Go với Elasticsearch cho ingestion và truy vấn.
- [OpenTelemetry](./opentelemetry) — Đưa logs, metrics và traces từ OpenTelemetry vào Elastic ecosystem.
