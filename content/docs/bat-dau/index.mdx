## Phạm vi dự kiến

Nhóm này đưa người học từ môi trường trống đến một cluster chạy được, có dữ liệu mẫu và truy vấn đầu tiên.

## Các bài trong nhóm

- [Cài đặt bằng Docker Compose](./cai-dat-docker-compose) — Tạo một môi trường Elasticsearch và Kibana cục bộ bằng Docker Compose.
- [Cài đặt native](./cai-dat-native) — Cài đặt Elasticsearch và Kibana trực tiếp trên máy Linux để học và thử nghiệm.
- [Kibana Dev Tools](./kibana-dev-tools) — Làm quen với Console của Kibana để gửi request REST và đọc response.
- [Index document đầu tiên](./index-document-dau-tien) — Tạo index, thêm document và kiểm tra dữ liệu bằng API cơ bản.
- [Truy vấn đầu tiên](./truy-van-dau-tien) — Viết các truy vấn tìm kiếm đầu tiên bằng Query DSL và đọc kết quả.
- [Sample data](./sample-data) — Nạp dữ liệu mẫu vào Kibana để thực hành Discover, dashboard và aggregation.
