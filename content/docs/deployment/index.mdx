## Phạm vi dự kiến

Nhóm này trình bày các mô hình triển khai, lựa chọn hạ tầng, high availability và cách ước lượng năng lực cluster.

## Các bài trong nhóm

- [Cluster topologies](./cluster-topologies) — Chọn vai trò node và topology cluster cho workload khác nhau.
- [Docker Compose](./docker-compose) — Tổ chức một stack Elastic nhiều service bằng Docker Compose cho môi trường thử nghiệm.
- [Kubernetes và ECK](./kubernetes-eck) — Triển khai và quản lý Elastic Stack trên Kubernetes bằng Elastic Cloud on Kubernetes.
- [Elastic Cloud](./elastic-cloud) — Khởi tạo và vận hành deployment trên Elastic Cloud cùng các lựa chọn managed service.
- [High availability](./high-availability) — Thiết kế cluster chịu lỗi với zone, replica, quorum và chiến lược failover.
- [Sizing và capacity planning](./sizing-capacity) — Ước lượng dung lượng, throughput, shard count và tài nguyên cần thiết.
