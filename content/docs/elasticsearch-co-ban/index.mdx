## Mục lục

## Phạm vi dự kiến
Các khả năng cốt lõi để lập mô hình dữ liệu, tìm kiếm và phân tích. Nội dung chi tiết sẽ được viết bổ sung theo từng trang.

## Các bài trong nhóm
- [Index và document](/docs/elasticsearch-co-ban/index-document) — Tìm hiểu vòng đời index, cấu trúc document và cách cập nhật dữ liệu.
- [Mapping và data types](/docs/elasticsearch-co-ban/mapping-data-types) — Thiết kế mapping cho text, keyword, số, ngày tháng, object và các kiểu dữ liệu khác.
- [Text analysis](/docs/elasticsearch-co-ban/text-analysis) — Tìm hiểu analyzer, tokenizer, token filter và cách tối ưu tìm kiếm văn bản.
- [Query DSL](/docs/elasticsearch-co-ban/query-dsl) — Xây dựng truy vấn JSON bằng query context, filter context và compound queries.
- [Relevance và scoring](/docs/elasticsearch-co-ban/relevance-scoring) — Giải thích điểm phù hợp, boosting, minimum should match và cách debug score.
- [Aggregations](/docs/elasticsearch-co-ban/aggregations) — Phân tích dữ liệu bằng bucket, metric, pipeline aggregation và các mẫu thường dùng.
- [Data streams](/docs/elasticsearch-co-ban/data-streams) — Sử dụng data stream cho dữ liệu append-only như logs, metrics và events.
