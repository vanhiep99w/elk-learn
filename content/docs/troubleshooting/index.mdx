## Phạm vi dự kiến

Nhóm này là bộ runbook placeholder cho các vấn đề về health, shard, latency, resource, ingestion và Kibana.

## Các bài trong nhóm

- [Cluster health](./cluster-health) — Đọc cluster health, node stats và các tín hiệu cho thấy cluster đang gặp vấn đề.
- [Shard allocation](./shard-allocation) — Điều tra shard unassigned, allocation explain và các nguyên nhân phân bổ thất bại.
- [Slow queries và latency](./slow-queries-latency) — Tìm nguyên nhân truy vấn chậm bằng profile, slow log và các chỉ số liên quan.
- [Rejected requests](./rejected-requests) — Phân tích thread pool, queue và rejected request do cluster quá tải.
- [Ingest failures](./ingest-failures) — Debug pipeline, mapping error, parsing error và document bị từ chối.
- [Kibana issues](./kibana-issues) — Xử lý các lỗi kết nối, saved object, visualization và alert trong Kibana.
