## Phạm vi dự kiến

Nhóm này đi sâu vào API và cơ chế cốt lõi thường được sử dụng khi xây dựng ứng dụng trên Elasticsearch.

## Các bài trong nhóm

- [Indices và documents](./indices-documents) — Tạo, quản lý index và hiểu vòng đời của document trong Elasticsearch.
- [Mapping và data types](./mapping-datatypes) — Thiết kế mapping, chọn data type và tránh các lỗi phổ biến khi tự động dynamic mapping.
- [CRUD và Bulk API](./crud-bulk) — Thực hiện create, read, update, delete và ghi dữ liệu hàng loạt hiệu quả.
- [Query DSL](./query-dsl) — Tổ chức các loại query trong Elasticsearch Query DSL cho lọc và tìm kiếm.
- [Full-text search](./full-text-search) — Xây dựng tìm kiếm văn bản, match query, phrase query và các biến thể liên quan.
- [Aggregations](./aggregations) — Tổng hợp dữ liệu theo bucket, metric và pipeline aggregation để phân tích.
- [Analyzers và tokenizers](./analyzers-tokenizers) — Tìm hiểu quá trình phân tích văn bản và cách tùy chỉnh analyzer cho ngôn ngữ.
- [Shards và replicas](./shards-replicas) — Giải thích phân mảnh, bản sao, phân bổ dữ liệu và trade-off của chúng.
