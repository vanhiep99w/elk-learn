## Phạm vi dự kiến
Các khái niệm nền tảng để hiểu Elasticsearch và toàn bộ Elastic Stack. Nội dung chi tiết sẽ được viết bổ sung theo từng trang.

## Các bài trong nhóm
- [Elasticsearch là gì?](/docs/nen-tang/elasticsearch-la-gi) — Giải thích Elasticsearch, bài toán tìm kiếm và phân tích mà nó giải quyết.
- [Kiến trúc Elastic Stack](/docs/nen-tang/kien-truc-elastic-stack) — Mô tả vai trò và luồng dữ liệu giữa Elasticsearch, Kibana, Logstash và các agent.
- [Các khái niệm cốt lõi](/docs/nen-tang/khai-niem-cot-loi) — Tổng hợp cluster, node, index, shard, replica, document và query.
- [Elasticsearch và các công cụ khác](/docs/nen-tang/elasticsearch-va-cong-cu-khac) — So sánh Elasticsearch với cơ sở dữ liệu, công cụ tìm kiếm và nền tảng phân tích khác.
- [JSON, document và REST API](/docs/nen-tang/json-document-rest-api) — Làm quen với mô hình document JSON và cách tương tác qua HTTP API.
- [Elastic Common Schema (ECS)](/docs/nen-tang/ecs) — Giới thiệu schema chung giúp chuẩn hóa dữ liệu logs, metrics, traces và security.
